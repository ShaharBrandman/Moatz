# Shadcn/UI library
Shadcn is a set of open source UI components auto-generated of the Shadcn CLI tool
to provide offline interaction to their UI components

# We use those UI components to make everything more beautiful
(Yes this is fucked up that we have thousands of files, but to make everything small and offline.. that's what works!)

# Core information to know
The use of the @ path is very important, it is auto-generated by Shadcn CLI and you don't want to fuck it up
it is configured tsconfig.json & vite.config.json
